Comprendre simplement

Connecter Vibe au monde extérieur avec MCP.

MCP (Model Context Protocol) permet à Mistral Vibe de découvrir et d'utiliser des outils proposés par des serveurs externes, sans intégrer directement chaque fonctionnalité dans le projet.

Découvrir le fonctionnement ↓ Voir les composants
01 · Le rôle de MCP

Pourquoi en a-t-on besoin ?

MCP étend les capacités de l'agent. Au lieu de développer chaque outil dans Vibe, on peut utiliser des outils mis à disposition par des serveurs MCP.

🧩

Étendre les capacités

L'agent peut accéder à des fonctionnalités qui ne sont pas intégrées directement dans Mistral Vibe.

🔎

Découvrir des outils

Vibe interroge les serveurs MCP configurés pour connaître les outils qu'ils proposent.

🔁

Utiliser une interface commune

Les outils découverts sont présentés à l'agent sous forme de proxies qu'il peut appeler.

02 · Le parcours d'un outil

Comment ça fonctionne ?

Le parcours simplifié d'un appel MCP dans Mistral Vibe.

Configurer

L'utilisateur configure un ou plusieurs serveurs MCP.

Découvrir

Le registre MCP recherche les outils disponibles sur ces serveurs.

Appeler

L'agent choisit un outil et l'appelle à travers le proxy créé par Vibe.

Recevoir

Le serveur exécute la demande et le résultat revient à l'agent.

04 · Dans le code

Les composants principaux

Chaque composant a un rôle précis dans la gestion des serveurs, des outils et des connexions MCP.

Registry

Découvre les serveurs MCP et les outils qu'ils mettent à disposition.

Tools

Construit les proxies et gère les appels aux outils MCP.

Pool

Gère et réutilise les connexions STDIO.

Descriptor cache

Conserve les descriptions des outils pour éviter des découvertes répétées.

Management

Gère l'ajout et la suppression des serveurs MCP.

Authorization

Définit les mécanismes liés à l'autorisation et à l'authentification.

05 · Connexion

Deux modes de communication

L'implémentation étudiée dans Mistral Vibe prend en charge HTTP et STDIO.

SERVEUR DISTANT

HTTP

Permet à Vibe de communiquer avec un serveur MCP distant via le réseau.

PROCESSUS LOCAL

STDIO

Permet à Vibe de communiquer avec un processus local à travers ses entrées et sorties standard.

À retenir : MCP est un moyen standardisé d'étendre les capacités de Mistral Vibe. Le registre découvre les outils, les proxies permettent à l'agent de les appeler, et les composants de connexion gèrent les échanges avec les serveurs.
